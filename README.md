# Nyra OS installer

A full-screen text installer for the Nyra OS ISO. It is temporary: the graphical installer comes
with the desktop.

## Status

Work in progress. For now the binary only prints its version and exits; the screens and the
installation steps come next.

## Build and test

Rust 1.85 or newer:

```sh
cargo build
cargo test
```
