Nyra OS installer                                                                               3 of 7 · Disk encryption
                                                                                                                        
  How should the disk unlock?                                                                                           
                                                                                                                        
  Nyra OS always encrypts the disk, so nobody can read it without a key.                                                
                                                                                                                        
    Unlock with this computer’s TPM                                                                                     
      Not available: this computer has no TPM, or it is switched off in the                                             
      firmware settings.                                                                                                
                                                                                                                        
  > Unlock with a password                                                                                              
      You type a password every time the computer starts.                                                               
                                                                                                                        
  You also get a recovery key. It opens the disk if the password stops                                                  
  working.
